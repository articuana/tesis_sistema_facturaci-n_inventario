# Módulo de inicio de sesión

Este proyecto contiene un front-end en React con Vite y un back-end en Node.js con Express.

## Front-end

- Carpeta: `frontend`
- Ejecutar:
  - `npm install`
  - `npm run dev`
- Accede en: `http://localhost:5173`

## Back-end

- Carpeta: `backend`
- Ejecutar:
  - `npm install`
  - `npm run dev`
- API de login: `POST http://localhost:4000/api/login`

## Datos de prueba
